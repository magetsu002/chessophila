# Chessophila

**Can a biologically grounded fruit-fly connectome learn useful chess preferences?**

Chessophila is an experimental harness for connecting a reproducible *Drosophila* neural simulation to chess decisions while keeping the scientific boundary explicit. The fly does not receive opening names or a hidden chess policy. Chess supplies legal candidate states; the neural system supplies physical choices; reward and plasticity are separate, versioned experimental components.

The repository currently provides the deterministic chess/choice boundary needed to integrate a real connectome backend:

```text
chess position
    -> legal resulting positions
    -> randomized left/right A/B bouts
    -> neural physical choice
    -> pairwise decision
    -> optional multi-candidate knockout
    -> complete bout log
```

The choice interface deliberately does **not** ship a fake "fly brain". A connectome simulator must satisfy the same narrow physical-choice contract without receiving chess notation, opening labels, engine rankings, or the identity of a rewarded move.

See [`docs/EXPERIMENT.md`](docs/EXPERIMENT.md) for the experiment contract and required controls.

## Design principles

- Legal chess moves are generated by the environment, not by the neural model.
- Candidate moves are represented to the neural system through resulting sensory states, not move labels.
- Left/right presentation is randomized so a fixed turning bias cannot masquerade as chess preference.
- Every neural bout must be reproducible and logged with enough provenance to audit the decoded choice.
- Engine evaluation, when used, remains an external and bounded critic; it never chooses moves for the fly.
- Negative results and failed controls remain part of the record.
- The visualization layer consumes real or replayed telemetry and never fabricates a neural decision.

## Scientific honesty

A connectome-derived simulation is not a perfect digital animal. Neural dynamics, sensory encoding, readout, plasticity, and embodiment each introduce assumptions. Chessophila versions those assumptions and keeps the biological model separate from the chess environment so claims can be tested rather than implied.
